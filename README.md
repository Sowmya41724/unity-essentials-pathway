\# Unity Essentials Pathway



A Unity project made while completing the Unity Essentials Pathway.

It has 5 learning scenes and a bonus scene that I extended with my own level design.



\## Play it

\[Play on Unity Play](https://play.unity.com/en/games/09e9b770-3335-42c2-971e-1347342ad081/essentials-project-web)



\## What's inside

\- 5 scenes, one for each unit I learned

\- Bonus scene: I extended the course project by adding a desert

&#x20; background, placing many collectibles for the player to find,

&#x20; and customizing the win message with a confetti effect



\## What I learned

\- Unity editor basics: scenes, GameObjects, prefabs, lighting

\- Level layout: placing collectibles and designing the play area

\- Using the Asset Store to add environments

\- Triggering a win message and particle effects (confetti)



\## Credits

\- Character and base gameplay features: provided by the Unity

&#x20; Essentials Pathway course

\- Background: LowPoly Environment Pack from the Unity Asset Store



\## Tools

Unity 6.6, C#



\## How to open

1\. Clone this repository

2\. Open Unity Hub, click Add, and select the project folder

3\. Open the scene from the Assets folder and press Play
